# Sports Tournament Management and Simulation System

## Project Overview
This project is a Sports Tournament Management and Simulation System for football.

The system manages:
- Teams
- Players
- Match scheduling
- Tournament progression
- Rankings
- Awards
- Match simulation

The project focuses on Data Structures and Algorithms.

---

## DSA Concepts Used

### ArrayList
Used for:
- Teams
- Players
- Matches
- Events

Purpose:
Dynamic storage and efficient traversal.

---

### HashMap
Used for:
- Team lookup
- Player grouping

Purpose:
Fast retrieval O(1).

---

### Stack
Used for:
- Match event undo system

Purpose:
LIFO behavior.

---

### Queue
Used for:
- Knockout progression

Purpose:
FIFO processing.

---

### Priority Queue
Used for:
- Rankings
- Awards

Purpose:
Efficient top-player retrieval.

---

### Arrays
Used for:
- Formations
- Fixed structures

---

### Graph Concept
Used to model:
- Teams → Vertices
- Matches → Edges

---

## Tournament Types
1. Round Robin
2. Double Round Robin
3. Knockout

---

## Complexity
Round Robin → O(n²)

Double Round Robin → O(2n²)

Knockout → O(n)
